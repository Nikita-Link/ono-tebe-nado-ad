# Оно тебе надо

Учебная проектная работа Яндекс Практикума: страница аукциона вещей, в которые никто не верил.

Автор: Nikita-Link.

Репозиторий: https://github.com/Nikita-Link/ono-tebe-nado-ad

[Оригинальный макет Figma](https://www.figma.com/design/PqHJvUBvwCsv8UmOUPWBXJ/1-спринт.-Проектная-работа?node-id=0-1)

## Просмотр

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны. Все изображения и шрифты входят в проект, пути относительные.

## Реализация

Семантическая HTML-разметка, CSS Grid и Flexbox, локальные шрифты Raleway, переиспользуемый оверлей и блок контактов. Основная версия соответствует макету шириной 1100px; ниже этой ширины включается дополнительная адаптация до 320px. Четвёртая карточка переносится на новую строку.

Это статическая учебная вёрстка. Обработка ставок, отдельные страницы лотов и загрузка дополнительных лотов не входят в задание; для соответствующих ссылок оставлены заглушки `#0`.

## Проверка

Проверены структура разметки, вложенность тегов, уникальность идентификаторов, локальные пути и загрузка изображений. В браузере проверены ширины 320, 375, 768, 1100 и 1440px: горизонтального переполнения нет. Отдельно проверены перенос четвёртой карточки и увеличенный текст.

Настройка `.github/workflows/tests.yml` сохранена из заготовки Практикума. Официальные автотесты запускаются после отправки изменений на GitHub; их результат следует проверить на вкладке Actions перед сдачей в Практикуме.
